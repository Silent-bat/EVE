03 — Technology

Three layers. One seamless experience.

Context Compiler

Core IP

A deterministic Go service that assembles a fixed-size context package — Tier 1 (identity core, pre-cached), Tier 2 (graph-retrieved situational context), Tier 3 (live turn). A power user with 8 months of history gets the same prompt size and latency as a new user. More history → better curation, not bigger cost.

Graph Memory Engine

Moat

A versioned knowledge graph in PostgreSQL — entities, relationships, temporal edges. 80% of queries resolve via pure graph traversal (zero embedding cost). Vector search as fallback for fuzzy queries only. Memory is transparent — users see and edit what EVE knows.

Voice Pipeline

V2

LiveKit WebRTC transport + ElevenLabs Turbo TTS with streaming chunk synthesis. Sentence-boundary buffering starts audio within 400ms. Silero VAD on-device for instant barge-in. OpenAI Realtime API for voice-to-voice mode when latency is the priority.
